# Help Us Out!

This website is a passion project. If you have any feedback, wether that be resources people should hear about, ways you would improve the website, or technical issues you encountered, we want to hear about it! Even if you would like to get more involved, let us know!

## Submit Your Feedback

### Map Update Requests

If you believe information on the map should be adjusted such as the location of a camera or the details listed with it please fill out [this form](https://docs.google.com/forms/d/17XvNN53pyA6sIHrYH8Lxi4KVdLy2wxthl-sBmOrhVXg/edit).

### Website Feedback

See something about the site you want changed? Fill out [this form](https://docs.google.com/forms/d/1irUT5gkPDLyncuAuGh_LhATx1ha8wWlZBdmi8dvI618/edit). This is the place to go if you believe we should add new links or resources, you have some design changes you want to see, or any other general feedback you have.

### Issue Reports

If there is a problem with the site please let us know [here](https://docs.google.com/forms/d/1vxGgXptl_tNqImPgyaM8aqotnG6VxJzrAk3vGfpvBro/edit).

## Contact Us
